Remote Overview

Menghubungkan Proyek Lokal ke Server Awan (Cloud)

1. Apa itu Remote Repository? +

Remote Repository adalah versi proyek Anda yang di-host di internet atau jaringan lain. Jika Lokal ada di laptop Anda, Remote ada di server seperti GitHub, GitLab, atau Bitbucket.

📖 Definisi:

Remote bertindak sebagai "Source of Truth" (Sumber Kebenaran). Tempat di mana semua anggota tim menyatukan kode mereka agar sinkron.

🏢 Kasus Real: Backup & Kolaborasi

Pernahkah laptop teman Anda rusak dan kodenya hilang? Jika tim menggunakan Remote, kode tersebut tetap aman di server. Remote memastikan pekerjaan tidak hilang dan bisa diakses siapa saja yang memiliki izin.

2. Mengapa Namanya 'Origin'? +

Saat Anda menghubungkan Git lokal ke server, Anda akan sering melihat kata origin. Apakah itu perintah wajib? Tidak.

🔍 Istilah: Origin

origin hanyalah nama panggilan (alias) standar untuk URL repositori remote Anda. Git menggunakan nama ini secara default agar kita tidak perlu mengetik URL panjang setiap kali ingin mengirim kode.

Anda bisa saja menamainya server-kantor atau pusat, tapi origin adalah standar industri yang dipahami semua developer dunia.

3. Perintah Utama Git Remote +

Berikut adalah cara mengelola hubungan antara laptop Anda dan server:

# Melihat daftar remote yang terhubung (-v untuk verbose/detail)
git remote -v

# Menambah hubungan remote baru
git remote add origin https://github.com/user/proyek.git

# Menghapus hubungan remote
git remote remove origin

# Mengubah URL remote (jika proyek pindah repo)
git remote set-url origin https://github.com/user/proyek-baru.git

4. Workflow: Push, Pull, & Fetch +

Bagaimana data berpindah antara Lokal dan Remote? Ada tiga pilar utama:

  • Push: Mengirim perubahan dari laptop Anda ke server.
  • Fetch: Mengecek apakah ada perubahan baru di server (tapi tidak langsung digabung).
  • Pull: Mengambil perubahan dari server dan langsung menggabungkannya ke kode Anda.
🏢 Standar Industri: Pull Before Push

Jangan pernah melakukan push sebelum Anda melakukan pull. Di industri, jika teman Anda sudah mengirim kode duluan, server akan menolak kode Anda sampai Anda mengambil (pull) pekerjaan teman Anda terlebih dahulu untuk menghindari konflik.
