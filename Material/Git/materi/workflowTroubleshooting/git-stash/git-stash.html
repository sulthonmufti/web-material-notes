git stash

Menyimpan Pekerjaan Sementara Tanpa Commit

1. Apa itu git-stash? +

git stash mengambil perubahan yang belum di-commit (baik yang sudah di-stage maupun belum) dan menyimpannya di tumpukan internal (stack) untuk sementara, sehingga Working Directory Anda kembali bersih.

📖 Istilah: Dirty Working Tree

Kondisi di mana ada file yang telah dimodifikasi tetapi belum disimpan dalam sebuah commit. Git seringkali menolak pindah branch dalam kondisi ini untuk mencegah kehilangan data.

🏢 Kasus Real: Interupsi Mendadak

Anda sedang membangun fitur API yang kompleks. Tiba-tiba klien menemukan bug tampilan. Anda harus pindah ke branch hotfix, tapi pekerjaan API Anda belum siap di-commit. Gunakan git stash, bereskan bug, lalu kembalikan pekerjaan API tadi.

2. Menyimpan & Mengambil (Basic) +

Dua perintah utama yang akan paling sering Anda gunakan:

# Menyimpan perubahan ke dalam stash
git stash

# Mengambil kembali perubahan terakhir dan menghapusnya dari stash
git stash pop
🔍 Pop vs Apply

pop mengambil data dan menghapusnya dari daftar laci. Sedangkan apply mengambil data tapi tetap meninggalkan salinannya di dalam laci (lebih aman).

3. Mengelola Banyak Stash +

Anda bisa menyimpan banyak pekerjaan sekaligus. Git akan mengaturnya seperti tumpukan buku.

# Menyimpan dengan pesan agar tidak bingung
git stash push -m "progres fitur login"

# Melihat daftar semua stash yang tersimpan
git stash list

# Mengambil stash spesifik berdasarkan indeks
git stash apply stash@{0}
4. Membersihkan Laci +

Jika stash sudah tidak diperlukan, jangan biarkan menumpuk karena akan membingungkan.

# Menghapus satu stash tertentu
git stash drop stash@{1}

# Menghapus SELURUH stash yang pernah dibuat
git stash clear
