Git Undo

Strategi Membatalkan Perubahan di Berbagai Level

1. Membatalkan File yang Baru Diedit (git restore) +

Gunakan ini jika Anda baru saja mengubah kode, belum melakukan git add, dan ingin mengembalikan file ke kondisi terakhir yang stabil.

# Membatalkan perubahan pada satu file
git restore index.html

# Membatalkan SEMUA perubahan di folder saat ini
git restore .
📖 Istilah: Discard Changes

Proses membuang perubahan yang belum disimpan ke area staging. Hati-hati: tindakan ini tidak bisa dibatalkan karena Git belum sempat mencatat perubahan tersebut.

🏢 Kasus Real: Eksperimen Gagal

Anda mencoba library baru yang ternyata merusak tampilan CSS. Daripada menghapus kode satu per satu secara manual, cukup gunakan git restore untuk kembali ke titik aman dalam sekejap.

2. Membatalkan "git add" (Unstaging) +

Pernahkah Anda tidak sengaja mengetik git add . padahal ada file rahasia (seperti .env) yang ikut terbawa? Ini cara mengeluarkannya.

git restore --staged config.json
🔍 Bedanya dengan menghapus file?

--staged hanya mengeluarkan file dari "daftar siap kirim". File tetap ada di laptop Anda, tapi tidak akan masuk ke dalam commit berikutnya.

3. Menghapus Commit (git reset) +

Digunakan ketika Anda sudah terlanjur melakukan git commit, tapi ada kesalahan di dalamnya.

# Soft Reset: Commit hilang, tapi kode tetap ada (untuk diperbaiki)
git reset --soft HEAD~1

# Hard Reset: Commit HILANG, kode juga HILANG (kembali total)
git reset --hard HEAD~1
⚠️ Aturan Emas Industri

JANGAN pernah gunakan git reset pada commit yang sudah di-push ke server (GitHub/GitLab). Ini akan merusak riwayat rekan tim Anda. Gunakan git revert sebagai gantinya.

4. Pembatalan Aman (git revert) +

Cara paling profesional untuk membatalkan commit yang sudah dipublikasikan. Revert tidak menghapus sejarah, melainkan membuat commit baru yang isinya adalah kebalikan dari commit yang salah.

git revert abc1234
📖 Istilah: Public History

Riwayat yang sudah dibagikan ke orang lain. Menjaga Public History tetap utuh (tidak dihapus) sangat penting agar kolaborasi tidak berantakan (conflict).
