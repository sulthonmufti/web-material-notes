Git Branching

Bekerja di Jalur Paralel dengan Aman

1. Apa itu Branch? (Konsep Pointer) +

Secara teknis, Branch hanyalah sebuah "penunjuk" (pointer) yang ringan menuju salah satu commit. Secara fungsional, ia adalah jalur pengembangan yang terisolasi.

📖 Istilah: HEAD

HEAD adalah penunjuk khusus yang memberi tahu Git di branch mana Anda sedang berdiri saat ini. Jika Anda pindah branch, HEAD ikut pindah.

🏢 Kasus Real: Fitur Baru vs Bugfix

Bayangkan Anda sedang membuat fitur "Chat", tapi tiba-tiba ada bug parah di halaman "Login". Anda cukup buat branch baru untuk perbaikan bug, selesaikan, lalu kembali ke branch "Chat" tanpa kehilangan progres apa pun.

2. Perintah Dasar Branching +

Berikut adalah cara membuat, melihat, dan menghapus jalur kerja Anda:

# Melihat daftar branch (lokal)
git branch

# Membuat branch baru
git branch fitur-keren

# Menghapus branch (pastikan sudah di-merge)
git branch -d fitur-keren

# Memaksa hapus branch yang belum di-merge
git branch -D fitur-eksperimen
3. Berpindah Antar Dimensi +

Setelah membuat branch, Anda harus "masuk" ke dalamnya untuk mulai bekerja.

🔍 Checkout vs Switch

Dulu kita menggunakan git checkout. Namun, sejak Git versi 2.23, diperkenalkan git switch yang lebih spesifik hanya untuk pindah branch agar tidak membingungkan.

# Cara modern untuk pindah branch
git switch nama-branch

# Membuat branch BARU sekaligus pindah ke sana
git switch -c fitur-login
4. Standar Industri: Naming & Strategy +

Di perusahaan profesional, kita tidak menamai branch sembarangan. Biasanya mengikuti pola Git Flow:

  • main / master: Kode suci yang sudah rilis ke publik (Production).
  • develop: Tempat berkumpulnya semua fitur yang sudah selesai di-test.
  • feature/nama-fitur: Tempat developer membuat fitur baru.
  • hotfix/nama-bug: Perbaikan darurat langsung untuk kode produksi.
5. Troubleshooting: Salah Nama & Branch Hilang +

Manusia sering melakukan kesalahan. Tenang, Git punya solusinya:

🛠️ Kasus: Salah Ketik Nama Branch

Jika Anda typo saat menamai branch yang sedang aktif:

git branch -m nama-yang-benar
🛠️ Kasus: Lupa Nama Branch Terakhir

Gunakan perintah ini untuk melihat branch mana yang paling aktif dikerjakan:

git branch --sort=-committerdate
