.gitignore

Mencegah File Sampah & Rahasia Masuk ke Repositori

1. Apa itu .gitignore? +

.gitignore adalah file teks khusus yang diletakkan di root folder proyek Anda. File ini berisi daftar nama file atau pola folder yang ingin Anda katakan kepada Git: "Jangan pernah awasi atau simpan file ini!"

📖 Istilah: Untracked Files

File yang ada di folder proyek Anda tapi belum pernah dimasukkan ke Git. Dengan .gitignore, file-file ini tidak akan muncul lagi di daftar git status.

🏢 Kasus Real: Menjaga Rahasia (Security)

Dalam proyek web, kita sering menyimpan API Key atau Password Database di file .env. Jika file ini tidak di-ignore dan terupload ke GitHub, hacker bisa mencuri data Anda dalam hitungan detik.

2. Cara Menulis Pola (Syntax) +

Anda bisa mengabaikan file spesifik, seluruh folder, atau menggunakan wildcard.

# Mengabaikan file spesifik
config.php

# Mengabaikan semua file dengan ekstensi tertentu
*.log
*.tmp

# Mengabaikan seluruh folder (tanda slash di akhir)
node_modules/
dist/

# Kecualikan file tertentu (tanda seru)
!important.log
3. Troubleshooting: Kenapa Tetap Muncul? +

Masalah paling umum: Anda menambahkan file ke .gitignore SETELAH file tersebut terlanjur di-commit. Git akan terus mengawasinya karena ia sudah masuk ke dalam sejarah.

🛠️ Solusi: Paksa Git Melepaskannya

Anda harus menghapus file tersebut dari "Cache" Git tanpa menghapus file fisiknya:

git rm --cached nama_file.txt
🏢 Kasus Real: Pembersihan node_modules

Developer sering lupa meng-ignore node_modules. Akibatnya, repo menjadi ratusan MB. Solusinya adalah melakukan git rm -r --cached node_modules, lalu commit ulang.

4. Lab: Cek Status Pengabaian +

Ketik nama file (misal: secret.env atau index.html) untuk melihat apakah Git akan memantau atau mengabaikannya berdasarkan peraturan standar.
