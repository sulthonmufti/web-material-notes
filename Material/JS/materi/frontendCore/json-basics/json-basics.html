JSON Basics

Standar Pertukaran Data Global yang Ringan dan Manusiawi

1. Apa itu JSON? +

JSON adalah singkatan dari JavaScript Object Notation. Meskipun namanya mengandung JavaScript, JSON adalah format teks murni yang bisa dibaca oleh hampir semua bahasa pemrograman (PHP, Python, Java, dll).

📖 Aturan Baku JSON:
  • Data disimpan dalam pasangan Key: Value.
  • Key harus dibungkus tanda kutip dua ("key").
  • Tipe data yang diizinkan: String, Number, Object, Array, Boolean, dan Null.

📝 Perbandingan Objek JS vs JSON

// Object JavaScript (Flexible)
{ name: 'Sulthon', age: 24 }

// JSON (Strict/Kaku)
{ "name": "Sulthon", "age": 24 }

🏢 Case Industri: API Response

Saat aplikasi Flutter atau Web Anda meminta data profil ke server, server akan mengirimkan paket "JSON" karena ukurannya yang sangat kecil dan ringan untuk dikirim melalui internet.

2. Mengubah Data ke JSON (stringify) +

Saat Anda ingin mengirim data dari aplikasi ke server (database), Anda harus mengubah Objek JavaScript menjadi String JSON terlebih dahulu.

📖 Istilah: Serialization Proses mengubah struktur data (objek) menjadi format linear (string) agar bisa disimpan atau dikirim.

🏢 Case Industri: LocalStorage

Browser hanya bisa menyimpan data berupa string. Jika Anda ingin menyimpan daftar belanja (array of objects) ke dalam localStorage, Anda wajib melakukan stringify terlebih dahulu.

3. Mengubah JSON ke Objek (parse) +

Setelah menerima data dari server atau mengambilnya dari storage, data tersebut masih berupa teks (string). Kita harus mengubahnya kembali menjadi objek agar bisa dimanipulasi oleh logika JavaScript.

📖 Istilah: Deserialization Kebalikan dari stringify; menghidupkan kembali string "mati" menjadi objek aktif yang bisa diakses propertinya.
'{ "user": "Sulthon", "isVerified": true }'

const data = JSON.parse(teksJSON);
console.log(data.user); // Output: Sulthon

🏢 Case Industri: Pengolahan Data API

Hampir semua interaksi fetch API membutuhkan .json() yang di balik layar menjalankan proses parsing agar data bisa ditampilkan ke tabel atau kartu UI.
