1. Sinkron vs Asinkron (Konsep Dasar) +

Secara alami, JavaScript bersifat Synchronous. Namun, proses berat seperti ambil data internet butuh asinkron agar website tidak "freeze".

📖 Istilah: Non-Blocking

Kemampuan JS menjalankan tugas di latar belakang tanpa menghentikan interaksi user lainnya (scrolling/klik).

Demo Dasar: Timer Simulation
Status: Siap
Analisis Kode Dasar:
function simulasi() {
    // setTimeout tidak menghentikan baris kode di bawahnya
    setTimeout(() => console.log("Selesai"), 3000);
}

🏢 Case Industri: Pengambilan Data API (Youtube Style)

Youtube memuat layout (header/sidebar) dulu, baru mengambil daftar video secara asinkron di latar belakang.

Visual Demo Case: YouTube Feed
Analisis Kode Case:
async function loadFeed() {
    showSkeleton(); // Visual placeholder
    const data = await fetchVideos(); // Tunggu data
    renderToUI(data); // Ganti skeleton dengan konten
}
2. Keyword: async dan await +

async dan await membuat kode asinkron terlihat rapi seperti kode sinkron biasa, membuatnya lebih mudah dibaca.

📖 Aturan Main:
  • async: Menandakan fungsi menghasilkan Promise.
  • await: Memberitahu JS untuk menunggu hasil Promise tersebut.
Demo Dasar: Sequence Control
Menunggu urutan...
Analisis Kode Dasar:
async function main() {
    await step1(); // Tunggu step 1 selesai
    await step2(); // Baru jalankan step 2
}

🏢 Case Industri: Sistem Authentication (Login)

Sistem harus menunggu verifikasi database sebelum mengizinkan user masuk ke Dashboard. Urutan sangat kritikal di sini.

Visual Demo Case: Authentication

Analisis Kode Case:
async function handleLogin() {
    const isValid = await checkDB(user); 
    if (isValid) goToDashboard();
}
3. Menangani Error (try...catch) +

Dalam proses asinkron, error seperti internet mati sangat umum. Kita menggunakan try...catch untuk jaring pengaman.

📖 Istilah: Exception Handling

Menangkap kesalahan agar aplikasi tidak berhenti mendadak saat terjadi gangguan jaringan atau server.

Demo Dasar: Test Connectivity
Status koneksi...
Analisis Kode Dasar:
try {
    const data = await apiCall();
} catch (err) {
    console.error("Waduh, koneksi bermasalah!");
}

🏢 Case Industri: Database Failover (Backup)

Jika server utama (A) gagal, sistem secara otomatis akan mencoba mengambil data dari server cadangan (B) di dalam blok catch.

Visual Demo Case: Server Failover
Server A: Online
Server B: Standby
> System ready...
Analisis Kode Case:
try {
    data = await fetchFromA();
} catch (err) {
    // Failover otomatis ke Server B
    data = await fetchFromB();
}
