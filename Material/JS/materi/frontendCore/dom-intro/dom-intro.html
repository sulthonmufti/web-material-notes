DOM Intro

Jembatan Antara Logika JavaScript dan Tampilan HTML

1. Apa itu DOM? (The Concept) +

DOM (Document Object Model) adalah representasi struktur halaman web dalam bentuk "Pohon" (Tree). Saat browser memuat HTML, ia mengubah setiap tag menjadi Object yang bisa "disentuh" oleh JavaScript.

📖 Istilah Baru: API & Tree Structure
  • API: Cara JS berkomunikasi dengan elemen browser.
  • Tree Structure: Susunan bertingkat dari html -> body -> div.

🏢 Case Industri: Live Update Data

DOM memungkinkan aplikasi seperti Live Score atau Stock Market memperbarui angka di layar secara instan tanpa perlu memuat ulang (refresh) seluruh halaman.

2. Menyeleksi Elemen (DOM Selection) +

Untuk mengubah isi web, Anda harus "menemukan" elemennya dulu. Ini seperti mencari alamat sebelum mengirim paket.

📖 Istilah Baru: Query & Selector
  • Query: Perintah pencarian elemen.
  • Selector: Nama ID, Class, atau Tag yang dicari.

Halo, Saya Elemen Target!

🛠️ Dapur Rekaman: Bedah Kode

const judul = document.getElementById("teks-demo");
// document adalah gerbang utama menuju DOM

🏢 Case Industri: Validasi Form

Saat user klik tombol "Submit", developer menggunakan querySelector untuk mengambil nilai dari input email dan mengeceknya secara otomatis.

3. Manipulasi Isi & Gaya +

Setelah elemen ditemukan, kita bisa mengubah isinya (innerHTML) atau gayanya (style).

Preview Box

🛠️ Dapur Rekaman: Bedah Logika

elemen.style.backgroundColor = "#222";
elemen.innerText = "Teks Berubah!";

🏢 Case Industri: Dark Mode Toggle

Fitur Dark Mode bekerja dengan memanipulasi classList atau properti style pada elemen body saat tombol diklik.
