1. Mendengarkan Interaksi (addEventListener) +

addEventListener adalah cara standar industri untuk menyuruh JavaScript "menunggu" sampai sesuatu terjadi pada elemen tertentu.

📖 Istilah: Event Listener & Callback
  • Event Listener: Alat pemantau yang dipasang pada elemen.
  • Callback Function: Blok kode yang dijalankan HANYA SAAT kejadian (event) terjadi.

🛠️ Dapur Rekaman: Penulisan Kode

const tombol = document.getElementById("btn");
tombol.addEventListener("click", function() {
    console.log("Tombol ditekan!");
});

🏢 Case Industri: Tracking Analitik

Perusahaan e-commerce menggunakan *Event Listeners* untuk mencatat tombol mana saja yang paling sering diklik pengguna guna menganalisis perilaku belanja (User Behavior).

3. Event Object & preventDefault +

Setiap event terjadi, JavaScript mengirimkan sebuah "Paket Data" berisi informasi lengkap tentang kejadian tersebut (seperti koordinat mouse atau tombol yang ditekan).

📖 Istilah: Event Object (e) Objek otomatis yang berisi properti seperti target (siapa yang diklik) dan preventDefault() (menghentikan perilaku bawaan browser).

🛠️ Dapur Rekaman: Menghentikan Refresh

form.addEventListener("submit", function(e) {
    e.preventDefault(); // Mencegah halaman reload
    console.log("Data diproses via AJAX!");
});

🏢 Case Industri: Single Page Application (SPA)

Aplikasi seperti Instagram atau Facebook menggunakan e.preventDefault() pada link navigasi agar berpindah halaman terasa instan tanpa perlu memuat ulang seluruh aset website.

4. Event Bubbling & Delegation +

Event Bubbling adalah fenomena di mana sebuah event "merambat" naik dari elemen terdalam ke elemen terluar (seperti gelembung air).

💡 Strategi: Event Delegation Daripada memasang listener ke 100 item list satu per satu, kita cukup pasang 1 listener pada parent-nya. Ini jauh lebih efisien untuk memori.

Saat membuat aplikasi To-Do List, Anda tidak tahu berapa banyak tugas yang akan dibuat user. *Event Delegation* memastikan tugas yang baru saja dibuat tetap bisa diklik/dihapus tanpa perlu pasang listener baru.
