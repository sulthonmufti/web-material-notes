API Fetch Masterclass

Menghubungkan Frontend dengan Dunia Luar melalui Network Request

1. Apa itu Fetch API? (Request & Response) +

Fetch API adalah antarmuka modern JavaScript untuk mengambil sumber daya (data) dari jaringan secara asinkron. Ini menggantikan metode lama (XMLHttpRequest).

📖 Istilah Baru: Endpoint

Alamat URL spesifik (seperti /api/users) yang disediakan oleh server untuk kita akses datanya.

Demo Dasar: Basic GET Request
Menunggu instruksi...
Analisis Kode Dasar:
fetch('https://api.example.com/data')
  .then(response => response.json()) // Mengubah response jadi objek JS
  .then(data => console.log(data)); // Mengolah data

🏢 Case Industri: User Profile Dashboard

Saat user masuk ke dashboard, frontend melakukan fetch ke endpoint profil untuk menampilkan nama dan foto user.

Visual Case: Fetch User Data

Klik tombol untuk memuat profil...

Analisis Kode Case:
async function loadUser() {
    const res = await fetch(USER_API);
    const user = await res.json();
    renderProfile(user); // Update UI dengan data server
}
2. Mengirim Data (HTTP POST) +

Jika GET digunakan untuk mengambil data, POST digunakan untuk mengirim data ke server (seperti membuat akun baru atau mengirim pesan).

📖 Istilah Baru: Request Body

Wadah tempat data kita diletakkan saat dikirim ke server, biasanya dalam format JSON.

Demo Dasar: POST Simulation
Data belum dikirim...
Analisis Kode Dasar:
fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name: 'Sulthon' }) // Data diconvert ke String
});

🏢 Case Industri: Sistem Registrasi / Post Komentar

User mengisi form, lalu data tersebut "dibungkus" dan dikirim ke database melalui method POST.

3. Menangani Error & HTTP Status +

Tidak semua fetch berhasil. Server memberikan kode status (seperti 404 atau 500) untuk memberi tahu apa yang terjadi.

📖 Istilah Baru: HTTP Status Code

200: OK, 404: Not Found (URL salah), 500: Server Error (Server rusak).

Demo Dasar: Status Checker
Pilih skenario...
Analisis Kode Dasar:
if (!response.ok) {
    throw new Error("Gagal mengambil data: " + response.status);
}

Visual Case: Error Toast Simulation
