Web Storage Masterclass

Menyimpan Data User secara Lokal untuk Experience yang Lebih Cepat

1. Local Storage (Permanen) +

LocalStorage adalah tempat penyimpanan di browser yang datanya tidak akan hilang meskipun browser ditutup atau komputer dimatikan.

📖 Istilah Baru: Persistence

Kondisi di mana data tetap terjaga/tersimpan dalam jangka waktu lama meskipun aplikasi dihentikan.

Demo Dasar: Simpan Nama
Halo, Tamu!
Analisis Kode Dasar:
localStorage.setItem('user', 'Sulthon'); // Simpan
const name = localStorage.getItem('user'); // Ambil

🏢 Case Industri: Dark Mode Preference

Pernah buka website yang otomatis ingat pilihan Dark Mode kamu? Itu menggunakan LocalStorage agar user tidak perlu klik tombol setiap ganti halaman.

Visual Case: Theme Switcher

Status: Light Mode

Analisis Kode Case:
// Cek saat halaman dimuat
const currentTheme = localStorage.getItem('theme');
if (currentTheme === 'dark') applyDark();
2. Session Storage (Temporer) +

SessionStorage mirip dengan LocalStorage, tapi datanya akan otomatis terhapus begitu tab browser ditutup.

📖 Istilah Baru: Volatile Storage

Penyimpanan yang bersifat sementara dan akan hilang jika sumber daya (tab/sesi) dihentikan.

Demo Dasar: Skor Sementara
Skor Sesi Ini: 0

*Coba refresh halaman (skor tetap), lalu coba tutup tab & buka lagi (skor reset).

Analisis Kode Dasar:
sessionStorage.setItem('score', '50'); // Hanya bertahan di tab ini

🏢 Case Industri: Multi-Step Form (Checkout)

Digunakan untuk menyimpan input user di Step 1 (Alamat) agar tidak hilang saat user lanjut ke Step 2 (Pembayaran), namun data bersih kembali setelah transaksi selesai.

Visual Case: Wizard Form Memory
> Belum ada data input...

sessionStorage.setItem('checkout_step1', JSON.stringify(data));
3. Menyimpan Objek (JSON Serialization) +

Web Storage hanya bisa menyimpan String. Untuk menyimpan objek atau array (seperti data user Laravel), kita harus mengubahnya jadi teks dulu.

📖 Istilah Baru: Stringify & Parse

Stringify: Objek $\rightarrow$ Teks. Parse: Teks $\rightarrow$ Objek.

Demo Dasar: Object Storage
Data: Kosong
Analisis Kode Dasar:
// Salah: localStorage.setItem('obj', myObj); -> [object Object]
// Benar:
localStorage.setItem('obj', JSON.stringify(myObj));

🏢 Case Industri: Offline Shopping Cart

Menyimpan daftar produk yang dipilih user ke dalam array of objects agar saat internet mati, daftar belanjaan mereka tidak hilang.

Visual Case: Cart State Persistence
  • 🛒 Keranjang kosong
Analisis Kode Case:
const cart = JSON.parse(localStorage.getItem('cart')) || [];
cart.push(newItem);
localStorage.setItem('cart', JSON.stringify(cart));
