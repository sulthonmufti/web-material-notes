DOM CSS

Mengontrol Estetika dan Visual Halaman secara Programatik

1. Manipulasi Inline Style (element.style) +

Cara paling langsung untuk mengubah CSS adalah melalui properti style. Ini akan menulis gaya langsung ke dalam atribut style="" di tag HTML.

📖 Istilah: CamelCase naming

Di CSS kita menulis background-color, tapi di JS kita menggunakan camelCase: backgroundColor.

Kotak Target

🛠️ Dapur Rekaman: Bedah Kode

const box = document.getElementById("box");
box.style.backgroundColor = "coral";
box.style.borderRadius = "50%";

🏢 Case Industri: Dynamic Progress Bar

Inline style sangat berguna untuk elemen yang nilainya berubah terus-menerus berdasarkan data, seperti loading bar atau presentase upload file.

2. Manipulasi Class (classList) +

Ini adalah Best Practice di industri. Alih-alih mengubah gaya satu per satu, kita cukup menambah atau menghapus "Nama Kelas" yang sudah kita siapkan di CSS.

📖 Istilah: Token List Methods
  • add(): Menambah kelas baru.
  • remove(): Menghapus kelas.
  • toggle(): Otomatis tambah jika tidak ada, hapus jika sudah ada (seperti saklar lampu).
Status: Netral

🛠️ Dapur Rekaman: Bedah Logika

// Cara profesional mengelola state
elemen.classList.add("active");
elemen.classList.toggle("dark-mode");

🏢 Case Industri: UI State Management

Digunakan untuk mengubah tampilan UI saat terjadi error (kotak input jadi merah) atau saat user mengaktifkan Dark Mode di seluruh aplikasi.

3. Membaca Gaya (getComputedStyle) +

Kadang kita perlu tahu berapa ukuran atau warna elemen yang sebenarnya diterapkan oleh browser (bukan yang kita tulis di inline style).

📖 Istilah: Read-Only Values getComputedStyle bersifat read-only. Anda bisa membaca nilainya, tapi tidak bisa mengubahnya langsung dari sini.

Klik tombol untuk mengecek warna teks ini!

🛠️ Dapur Rekaman: Cara Mengakses

const gaya = window.getComputedStyle(elemen);
console.log(gaya.color); // Mengembalikan nilai RGB asli

🏢 Case Industri: Responsive Check

Developer menggunakan ini untuk mengecek apakah elemen tertentu sedang tersembunyi (display: none) sebelum menjalankan animasi tertentu agar tidak terjadi error visual.
