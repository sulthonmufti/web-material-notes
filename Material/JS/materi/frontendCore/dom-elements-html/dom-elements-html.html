DOM Elements

Menciptakan, Menghapus, dan Mengelola Atribut HTML melalui JavaScript

1. Membuat Elemen Baru (createElement) +

JavaScript memungkinkan kita menciptakan tag HTML baru secara dinamis tanpa harus menulisnya di file .html.

📖 Istilah Baru: Create & Append
  • createElement: Perintah untuk "melahirkan" elemen baru di memori.
  • appendChild: Menempelkan elemen yang sudah dibuat ke dalam halaman web (sebagai anak terakhir).

List kosong...

const baru = document.createElement("li");
baru.innerText = "Item Baru";
parent.appendChild(baru);

🏢 Case Industri: Infinite Scroll / Feed

Saat Anda men-scroll media sosial dan muncul postingan baru, JavaScript menggunakan createElement untuk membuat "kartu" postingan tersebut secara otomatis.

2. Menghapus Elemen (remove) +

Sama seperti membuat, kita juga bisa membuang elemen yang sudah tidak diperlukan dari halaman web.

📖 Istilah Baru: Garbage Collection Menghapus elemen dari DOM membantu browser menghemat memori karena elemen tersebut tidak lagi diproses.
⚠️ Ada pesan penting untuk Anda! 
const target = document.querySelector(".alert");
target.remove(); // Elemen hilang seketika

🏢 Case Industri: Dismissible Alerts

Digunakan pada fitur notifikasi atau iklan "pop-up" di mana user bisa menekan tombol (X) untuk menghilangkan elemen tersebut secara permanen dari layar.

3. Atribut & Properti (setAttribute) +

Atribut adalah informasi tambahan pada tag (seperti src pada img, href pada a, atau type pada input).

📖 Istilah Baru: Getter & Setter
  • getAttribute: Mengambil nilai atribut (Membaca).
  • setAttribute: Mengubah atau menambah atribut (Menulis).

🏢 Case Industri: Toggle Password Visibility

Fitur ikon mata pada kolom password bekerja dengan mengubah atribut type="password" menjadi type="text" menggunakan JavaScript.
