Practice: DOM Elements & HTML

Latihan createElement, remove, dan setAttribute/getAttribute berdasarkan materi DOM Elements.

📋 Instruksi Practice

Buka file dom-elements-html-practice.js dan isi function sesuai tugas di bawah. Gunakan:

  • document.createElement() untuk membuat elemen baru
  • parent.appendChild(child) untuk menempelkan elemen
  • elemen.remove() untuk menghapus elemen dari DOM
  • getAttribute() dan setAttribute() untuk membaca/mengubah atribut

1. Tambah Item ke List

Isi function tambahItemList() dan hapusSemuaItem() di JS:
- Saat tombol Tambah Item diklik, buat elemen <li> baru berisi teks "Item ke-[nomor]" dan tambahkan ke #practice-list.
- Saat tombol Hapus Semua diklik, kosongkan semua anak di #practice-list.

2. Dismissible Alert

Isi function tutupAlert():
- Seleksi elemen dengan id alert-latihan dan panggil .remove() agar box hilang dari halaman.

⚠️ Ini adalah alert latihan. Klik tombol untuk menghapusku dari DOM.

3. Toggle Password Visibility

Isi function togglePasswordPractice():
- Seleksi input #password-practice, baca atribut type dengan getAttribute().
- Jika type="password" ubah menjadi text, kalau tidak ubah kembali jadi password menggunakan setAttribute().
