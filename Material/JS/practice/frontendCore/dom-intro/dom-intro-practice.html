Practice: DOM Intro

Implementasikan materi Seleksi Elemen, Manipulasi Teks, dan Manipulasi Gaya di file dom-intro-practice.js

📋 Instruksi Study Case

Buka file dom-intro-practice.js. Isi setiap function sesuai keterangan di bawah. Gunakan:

  • document.getElementById("id-elemen") untuk seleksi by ID
  • elemen.innerText atau elemen.innerHTML untuk mengubah teks
  • elemen.style.sifatCSS untuk mengubah gaya (misal: backgroundColor, color)
  • elemen.classList.toggle("nama-class") untuk menambah/menghapus class
  • inputElement.value untuk membaca isi input

1. Penghitung Klik
