Study case mengikuti materi inline style, classList, dan getComputedStyle. Isi tubuh function di <script> bawah halaman.

Study case: kartu tugas + progress

Bayangkan satu fitur kecil di dashboard: batang progres upload (nilai dinamis), kartu status tugas (sukses/gagal), dan tombol untuk membaca gaya yang benar-benar dipakai browser pada judul.

  • Bagian 1 — ubah lebar/warna batang dengan element.style (ingat camelCase, mis. backgroundColor, width).
  • Bagian 2 — kelola tampilan kartu dengan classList.add / remove / toggle pada class yang sudah didefinisikan di <style>.
  • Bagian 3 — baca gaya terkomputasi dengan window.getComputedStyle(el), lalu tampilkan ke #computed-output.

Referensi implementasi contoh ada di materi: Material/JS/materi/frontendCore/dom-css/

1) Batang progress (inline style)

Target elemen: #progress-fill. Set style.width sebagai persen (string, mis. "50%") dan opsional ubah style.backgroundColor.

2) Status kartu tugas (classList)

Elemen: #task-card. Class state: task-neutral, task-success, task-error (hanya satu state aktif). Class opsional: task-urgent — pakai toggle. Update juga teks #task-card-label agar sesuai status.

Judul tugas contoh

Status: netral

3) Baca gaya terkomputasi

Baca misalnya color dan fontSize dari #task-title setelah state kartu berubah, lalu isi #computed-output (boleh pakai innerText).
